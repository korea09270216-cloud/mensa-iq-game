# 멘사 스타일 IQ 테스트 게임

### ▶ [지금 플레이하기](https://korea09270216-cloud.github.io/mensa-iq-game/)

> **재미용 테스트입니다.** 멘사(Mensa)와 무관하며, 공식 IQ 검사가 아닙니다. 결과 IQ는 재미를 위한 환산값입니다.

3×3 도형 추론 · **35문항 · 25분** · 뒤로 갈수록 어려워집니다.
멘사 온라인 연습 테스트와 같은 형식입니다: **완전 흑백 선화**로 그려진 도형 8개를 보고, 빈칸에 들어갈 도형을 **보기 6개(A~F)** 중에서 고릅니다.

## 흐름
1. **표지** — 이름, 나이 입력 후 시작
2. **테스트** — 보기를 누르면 **바로 다음 문제로** 넘어갑니다. 시간은 오른쪽 위에 항상 표시됩니다. 이전 문제로 돌아가 답을 바꿀 수도 있습니다.
3. **결과** — 당신의 IQ, 상위 N% / 하위 N%, IQ에 대응하는 동물·위인 등급 (원숭이 → … → 아인슈타인)

## 문제는 이렇게 만들어집니다
저장된 문제 목록이 아니라 **규칙을 조합하는 생성기**가 풀 때마다 새 문제를 만듭니다. 외워서 풀 수 없습니다.
모든 문제는 오리지널이며, 실제 멘사 문제(이미지 포함)를 복사하지 않았습니다.

참고 테스트의 순서와 규칙 계열을 분석한 **35칸 설계도**입니다. 2026-11-23 기준 35문항 모두 이미지를 읽어 특징을 전사하고, 규칙으로 보기 하나가 선택되는지 코드로 확인했습니다. 마지막 문항들은 [공개 풀이 설명](https://puzzling.stackexchange.com/questions/89281/mensa-norway-last-3-questions)을 참고한 뒤 원본 8칸과 보기 6개로 재검증했습니다. 공식 정답표와 대조한 결과는 아닙니다. 생성 문항의 유일성 검증과 참고 문항의 규칙 검증은 별개입니다.

| 구간 | 규칙 계열 (설계도 순서) |
|---|---|
| 앞부분 (1~9) | 칸 위치 이동 · 바깥틀×안쪽기호 직교 · 이중 라틴 · 망치/화살표(회전×위치) · 블록(윗줄×아랫줄) · 칸 수 증가 · 위/아래 점 묶음 순환 · 십자+점+네모 |
| 중간 (10~23) | 가운데=합집합 · 대각선 사각형(색 패턴) · 도형×채우기 · 도형×선 방향 · 쉐브론 · 우산 · 시곗바늘(불규칙 합산) · 선분/요소 겹침·XOR · 요소 분할 · 위/아래 합성 · 기호 세 개 |
| 뒷부분 (24~35) | 8방향 살 XOR · 고리/점 AND · 살 XOR와 점 AND · 집게 · 꺾은선 XOR · 좌우 개수 합산 · 3상태 덧셈 · 검은 칸 XOR · 교집합 후 상하반전 · 대각선 접기 · 흰점 회전과 검은점 가림 · 두 대각선 요소 합성 |

규칙의 종류는 크게 세 가지입니다.
- **클래스형** — 행/열/대각선마다 값이 정해짐 (직교, 라틴 방진, 값이 반복되는 패턴)
- **합산형** — 값 = R[행] + C[열] (증가량이 불규칙해도 됨, 시곗바늘)
- **집합형** — 3번째 칸 = 두 칸의 합/XOR/교집합/차집합, 가운데 칸 = 합집합, 한 줄이 요소를 나눠 가짐, 두 층을 따로 연산

- **보기:** 정답 1개 + 오답 5개. 오답은 한 요소만 틀린 것, 이웃 칸 도형을 복사한 것, 다른 연산의 결과 등 그럴듯하게 만듭니다.
- **쉬운 문제 방지:** 줄이나 열이 그대로 반복되는 문제, 정답이 이미 보이는 칸과 똑같은 문제는 출제하지 않습니다.
- **정답 검증:** 별도의 풀이기가 보이는 8칸만으로 정답이 하나로 정해지는지 다시 확인합니다.

## 로컬 실행
빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 간단한 서버로 실행하세요.

```bash
npx serve .
```

## 문제 생성기 검증
```bash
node tools/verify.js        # 칸별/난이도별 서로 다른 문제 수, 풀이기 추론 = 정답, 보기 6개 서로 다름, 시험 내 중복 없음 등
```

URL에 `?seed=숫자`를 붙이면 같은 시험을 재현할 수 있습니다. 키보드: `A`~`F`(또는 `1`~`6`) 보기 선택 · `←`/`→` 이동
