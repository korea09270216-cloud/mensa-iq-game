# 멘사 스타일 IQ 테스트 게임

### ▶ [지금 플레이하기](https://korea09270216-cloud.github.io/mensa-iq-game/)

> **재미용 테스트입니다.** 멘사(Mensa)와 무관하며, 공식 IQ 검사가 아닙니다. 결과 IQ는 재미를 위한 환산값입니다.

30문항 · 25분 · 뒤로 갈수록 어려워지는 비언어(도형·숫자) 추론 퀴즈입니다.

## 흐름
1. **표지** — 이름, 나이 입력 후 시작
2. **테스트** — 30문항(쉬움 10 → 보통 12 → 어려움 8). 이전/다음으로 오가며 답 변경 가능
3. **결과** — 당신의 IQ, 상위 N% / 하위 N%, IQ에 대응하는 동물·위인 등급 (원숭이 → … → 아인슈타인)

## 특징
- **문제는 매번 새로 생성됩니다.** 저장된 목록이 아니라 규칙을 조합하는 생성기라서, 외워서 풀 수 없습니다.
  - 도형 행렬(3×3), 도형 수열, 숫자 수열, 숫자 표 — 4가지 유형
  - 난이도 구간마다 서로 다른 문제가 수천 가지 이상 (`node tools/verify.js`로 확인)
  - 모든 문제는 오리지널이며, 실제 멘사 시험 문제가 아닙니다.
- **시간은 조용하게.** 평소에는 시간이 보이지 않고, 오른쪽 위 시계 아이콘을 누르거나(또는 `T` 키) 마우스를 올릴 때만 남은 시간이 나타납니다. 새로고침해도 시간은 리셋되지 않습니다.
- 키보드: `1`~`6` 보기 선택 · `←`/`→` 이동 · `Enter` 다음 · `T` 남은 시간

## 로컬 실행
빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 간단한 서버로 실행하세요.

```bash
npx serve .
```

## 문제 생성기 검증
```bash
node tools/verify.js        # 난이도별 서로 다른 문제 수, 정답 1개, 보기 6개 서로 다름, 시험 내 중복 없음 등
```

URL에 `?seed=숫자`를 붙이면 같은 시험을 재현할 수 있습니다.
