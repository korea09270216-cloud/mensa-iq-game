# 멘사 스타일 IQ 테스트 게임

### ▶ [지금 플레이하기](https://korea09270216-cloud.github.io/mensa-iq-game/)

> **재미용 테스트입니다.** 멘사(Mensa)와 무관하며, 공식 IQ 검사가 아닙니다. 결과 IQ는 재미를 위한 환산값입니다.

3×3 도형 추론 · 30문항 · 20분 · 뒤로 갈수록 어려워집니다.
실제 멘사코리아 입회 테스트처럼 **8개의 도형을 보고 빈칸에 들어갈 도형을 보기 6개 중에서 고르는** 형식입니다.

## 흐름
1. **표지** — 이름, 나이 입력 후 시작
2. **테스트** — 보기를 누르면 **바로 다음 문제로** 넘어갑니다. 시간은 오른쪽 위에 항상 표시됩니다. 이전 문제로 돌아가 답을 바꿀 수도 있습니다.
3. **결과** — 당신의 IQ, 상위 N% / 하위 N%, IQ에 대응하는 동물·위인 등급 (원숭이 → … → 아인슈타인)

## 문제는 이렇게 만들어집니다
저장된 문제 목록이 아니라 **규칙을 조합하는 생성기**가 풀 때마다 새 문제를 만듭니다. 외워서 풀 수 없습니다. 모든 문제는 오리지널이며 실제 멘사 문제가 아닙니다.

도형 하나는 여러 겹(바깥 도형 · 빗금 · 안쪽 도형 · 점/표식)으로 이루어지고, 레이븐 행렬의 대표 규칙이 겹마다 적용됩니다.

| 규칙 | 예 |
|---|---|
| 고정 (Constant) | 한 줄 안에서 같은 값 유지 |
| 점진 변화 (Progression) | 명암·크기·점 위치가 한 단계씩 변함 |
| 3값 순환 (Distribute Three) | 한 줄에 도형·빗금 세 종류가 한 번씩 |
| 겹침 연산 (Arithmetic) | 3번째 칸 = 1번째와 2번째의 합 / XOR / 교집합 / 차집합 |

- **난이도:** 쉬움 10문항(규칙 1개) → 보통 12문항(규칙 2~3개, 겹침 연산 일부) → 어려움 8문항(규칙 3~4개 + 겹침 연산 다수)
- **보기:** 정답 1개 + 오답 5개. 오답은 한 요소만 틀린 것, 이웃 칸 도형을 복사한 것, 다른 연산의 결과 등 실제 시험처럼 그럴듯하게 만듭니다.
- **정답 검증:** 별도의 풀이기가 보이는 8칸만으로 정답이 하나로 정해지는지 다시 확인합니다.

## 로컬 실행
빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 간단한 서버로 실행하세요.

```bash
npx serve .
```

## 문제 생성기 검증
```bash
node tools/verify.js        # 난이도별 서로 다른 문제 수, 풀이기 추론 = 정답, 보기 6개 서로 다름, 시험 내 중복 없음 등
```

URL에 `?seed=숫자`를 붙이면 같은 시험을 재현할 수 있습니다. 키보드: `1`~`6` 보기 선택 · `←`/`→` 이동
