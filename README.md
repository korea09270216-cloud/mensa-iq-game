# 멘사 스타일 IQ 테스트 게임

### ▶ [지금 플레이하기](https://korea09270216-cloud.github.io/mensa-iq-game/)

> **재미용 테스트입니다.** 멘사(Mensa)와 무관하며, 공식 IQ 검사가 아닙니다. 결과 IQ는 재미를 위한 환산값입니다.

3×3 도형 추론 · **35문항 · 25분** · 뒤로 갈수록 어려워집니다.
멘사 온라인 연습 테스트와 같은 형식입니다: **완전 흑백 선화**로 그려진 도형 8개를 보고, 빈칸에 들어갈 도형을 **보기 6개(A~F)** 중에서 고릅니다.

## 흐름
1. **표지** — 이름, 나이 입력 후 시작
2. **테스트** — 보기를 누르면 **바로 다음 문제로** 넘어갑니다. 시간은 오른쪽 위에 항상 표시됩니다. 이전 문제로 돌아가 답을 바꿀 수도 있습니다.
3. **결과** — 당신의 IQ, 상위 N% / 하위 N%, IQ에 대응하는 동물·위인 등급 (원숭이 → … → 아인슈타인)

## 문제는 이렇게 만들어집니다
저장된 문제 목록이 아니라 **규칙을 조합하는 생성기**가 풀 때마다 새 문제를 만듭니다. 외워서 풀 수 없습니다.
모든 문제는 오리지널이며, 실제 멘사 문제(이미지 포함)를 복사하지 않았습니다. 형식과 난이도 곡선만 참고했습니다.

| 유형 | 내용 |
|---|---|
| `pix` | 3×3 칸 위의 검은 칸 패턴이 이동·회전·반전하거나, 두 칸이 합/XOR/교집합/차집합 연산으로 겹침 |
| `combo` | 바깥 도형 × 안쪽 기호 × 채우기(흰색/회색/검정)가 3값 순환 (라틴 방진) |
| `glyph` | 우산·화살표·깃발·망치 모양이 45°씩 회전하고 속이 흰색/검정/빗금으로 바뀜 |
| `overlay` | 도형·선분·원+점/선 같은 요소가 겹침 (3번째 칸 = 두 칸의 합/XOR/교집합/차집합), 가로/세로 방향 모두 |

- **난이도:** 쉬움 12 → 보통 13 → 어려움 10문항. 각 구간 안에서도 쉬운 것부터 나옵니다.
- **보기:** 정답 1개 + 오답 5개. 오답은 한 요소만 틀린 것, 이웃 칸 도형을 복사한 것, 다른 규칙의 결과 등 그럴듯하게 만듭니다.
- **정답 검증:** 별도의 풀이기가 보이는 8칸만으로 정답이 하나로 정해지는지 다시 확인합니다.

## 로컬 실행
빌드 과정이 없는 정적 사이트입니다. `index.html`을 열거나 간단한 서버로 실행하세요.

```bash
npx serve .
```

## 문제 생성기 검증
```bash
node tools/verify.js        # 난이도별 서로 다른 문제 수, 풀이기 추론 = 정답, 보기 6개 서로 다름, 시험 내 중복 없음 등
```

URL에 `?seed=숫자`를 붙이면 같은 시험을 재현할 수 있습니다. 키보드: `A`~`F`(또는 `1`~`6`) 보기 선택 · `←`/`→` 이동
